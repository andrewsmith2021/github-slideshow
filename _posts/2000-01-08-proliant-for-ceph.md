> "Ceph is free; running it isn't. HPE makes Ceph cheaper and safer to operate at scale."

| Pillar | HPE offering |
|---|---|
| **Servers tuned per Ceph role** | Dense 1P NVMe ProLiant (DL325/DL345 class); DL380/DL385 for capacity |
| **Fleet lifecycle** | Compute Ops Management firmware baselines; iLO remote management and security |
| **Network for rebuild traffic** | Juniper/Aruba 25/100/400GbE + Apstra |
| **Observability** | OpsRamp ingests Ceph's Prometheus metrics, ties issues to root cause |
| **Support & buying** | One vendor for server to switch; GreenLake capacity on demand |

<small>Don't replace Comcast's Ceph; be the best place to run it. Offer the X10K where turnkey fits (AI, backup, media). Pilot: measure rebuild time, latency, operator hours per PB.</small>
